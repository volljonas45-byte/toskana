# Bilder-Ordner

Hier kommen alle Bilder für die Website rein. Sobald du sie hier ablegst, sag mir Bescheid – ich tausche dann die aktuellen Unsplash-Platzhalter im Code gegen deine Bilder aus.

## Struktur & was wo reinkommt

```
public/images/
├── logo/          ← Logo (SVG bevorzugt, alternativ PNG transparent)
├── hero/          ← Großes Bild ganz oben (z.B. Café Außenansicht mit Terrasse)
├── cafe/          ← Café innen, Korbsessel, Kuchen, Frühstück
├── hofladen/      ← Produkte, Regale, Eier, Marmelade, etc.
├── wochenmarkt/   ← Marktstand Leingarten
├── piaggio/       ← Der gelbe Piaggio Ape Flitzer
├── torten/        ← Tortenbäckerei, einzelne Torten
└── galerie/       ← weitere Bilder für die große Bild-Galerie
```

## Empfehlungen

- **Format:** JPG (für Fotos) oder WebP (kleiner)
- **Auflösung:** mindestens 1600px breit für Hero, sonst ~1200px reicht
- **Logo:** SVG ist am besten (skaliert verlustfrei)
- **Dateinamen:** ohne Leerzeichen und Sonderzeichen, kleinschreibung
  - Gut: `cafe-terrasse.jpg`, `piaggio-vor-hof.jpg`
  - Schlecht: `Café Terrasse (1).jpg`

## So fügst du Bilder ein

1. Bild in den passenden Unterordner kopieren
2. Mir per Chat schreiben: „Bilder sind drin" (oder einfach beschreiben was wo ist)
3. Ich tausche die Platzhalter im Code aus und pushe zu GitHub – nach ~3 Min ist es live
